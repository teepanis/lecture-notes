# ศึกษา Complex Plane Wave

ใช้ภาษาไพทอนใน [https://matplotlib.online](http://matplotlib.online) หรือเขียนในเครื่องคอมพิวเตอร์ของตนเอง แต่ใช้ออนไลน์สะดวกกว่ามาก

เขียนโค้ดสั้น ๆ ต่อไปนี้

```python
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.animation as ani

fig, ax = plt.subplots()

def update(t):
    x = np.linspace(0,2*np.pi,100)
    y0 = (x)**2
    ym = (x-0.2*t)**2
    ax.clear()

    #y1 = np.cos(3*x-0.2*t)
    #y2 = np.sin(3*x-0.2*t)
    #ax.plot(x,y1,label='Re(Ψ)')
    #ax.plot(x,y2,label='Im(Ψ)')

    ax.plot(x,y0,label='$y(x)$')
    ax.plot(x,ym,label='$y(x-v t)$')
    ax.set_ylim([-2,+2])
    ax.grid()
    ax.legend(loc='upper right')


ani.FuncAnimation(fig, update, frames=100)

plt.show()
```

จะเห็นกราฟพาราโบล่าวิ่งไปทางขวา ปรับแก้บรรทัด `y = ...` เพื่อเป็นฟังก์ชันตามเนื้อหาของการบรรยาย

สำหรับบรรทัดที่ขึ้นต้นด้วย `#` คือ comment แปลว่าทำการปิดคำสั่งดังกล่าวชั่วคราว ลองลบสัญลักษณ์ `#` ข้างหน้าออกแล้วรันอีกครั้ง จะเห็นคลื่นระนาบเชิงซ้อน (Complex Plane Wave) ทั้งส่วนจริงและส่วนจินตภาพวิ่งไปทางขวามือ
